# Refugee_Employment_in_Kampala
Labor force status of adults aged 18–65 in Kampala

I used Uganda's 2022 Harmonized Host and Refugee Labor Market Survey to compare refugees with Ugandan nationals. 
I looked at:
- differences in employment
- whether workers' jobs match their skills
- how employment among refugees changes with time in Uganda

The full analysis and visualization code is available in: `refugee-labor-access.Rmd`
